# MV 创意工坊 0.11.0：浏览功能与社区数据边界

更新：2026-10-09。用户已取消 Harness 账号登录接入；本版不要求工坊账号。

## 本版已完成

- 组合筛选：搜索、类型、许可证、标签、歌词内容、安装状态（全部／已安装／有更新）与插件兼容性；清除筛选并显示结果数。
- 排序：最近更新、名称、目录顺序；缺失日期放后，数值／名称相同时保持稳定顺序。
- 原生详情按钮与独立原作链接，避免嵌套交互和键盘冲突；三套皮肤、明暗及窄面板容器布局。
- GitHub／官方华为 HTTPS 静态镜像的下载流程不变，继续按固定提交、大小和 SHA-256 校验。歌词等授权资源随包，音乐自备。

## 没有上线的功能

**共享下载统计、匿名投票后台、真实热门分数及自动授奖计算尚未部署。** 本版不注册任何社区 Host Remote，不连接新 API，不建立数据库，不发送安装事件／投票，不访问 Harness 登录凭据。

当前生产 API 没有 `workshopCommunity` 方法，因此默认界面隐藏社区统计、奖杯筛选和下载／点赞／热门排序，而不是展示一排无法使用的按钮或伪造计数。账号／授权等待提示及全部点赞按钮已移除。普通浏览、安装与排序不受影响。

## 可选只读展示基础

保留独立的严格社区快照解析器及可选客户端 `api.workshopCommunity({})` 适配点，供后续受信公共数据服务使用；这不是已注册的远端方法或现行公开 API。

仅当确有该只读接口时，展示其公共计数、按已知指标排序及声明政策对应的授奖记录。未知计数为 `null`，界面显示 `—`；真实的零仍为 `0`。计数为非负安全整数，已知去重值不得大于成功次数；缺失值排后，缓存标明时间。大数字完整显示，不拆断为多行。

快照中的 `viewer`／`likedByViewer` 是内部兼容保留字段，不是本版提供的账号功能。客户端一律删除其个人姓名、身份状态和个人点赞，不读取本地账号或声称已登录。结构解析不认证、不授奖、不计算热度。奖杯仅显示服务明确给出且匹配声明政策的记录；不会由本地计数自动生成。

## 后续匿名服务的边界（待另行实现／确认）

取消账号不等于已有共享后台或完全防刷。若以后启用匿名计数／点赞，应明确是设备／客户端去重而不是去重人数，并说明重装、更换设备等限制；不得沿用 Harness 账号去重措辞。临时安装标识不能冒充真实账户，也不能提供绝对防刷保证。

成功安装报告须在全文件验证并完成安装后产生；同一事件重试应持久幂等，投票提交目标状态而非 toggle。需服务端限流、异常检测、隐私说明与可解释的热门／授奖政策。统计传输失败不得回滚安装。是否部署独立后台和数据库、具体指标口径与奖杯门槛，仍需单独确定；现有 OpenClaw 和静态镜像未改。

## 验证说明

纯数据／客户端测试与生产 React 浏览器 QA 使用明确的本地合成数据，不代表线上用户、真实下载或投票。发布验证分别覆盖默认无社区接口界面与可选只读数据界面；新版本不宣称实现了社区服务器。
