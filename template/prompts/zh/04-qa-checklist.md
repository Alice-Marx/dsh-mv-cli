# 04 自检清单（交付前逐条确认）

## 必须通过

- [ ] `mv_pack_validate`（path = 包文件夹）没有错误；mv.json 是合法 JSON，`canvas.renderer` 为 `"script"`、`canvas.script` 指向 `scenes.js`。
- [ ] 歌词来自用户的文件，没有编造、改写或补全；时间轴单调递增，不超过时长。
- [ ] 没有修改、转码、删除音频；没有联网下载素材；只改动了包文件夹里的文件。
- [ ] scenes.js 没有 import / require / eval / new Function / fetch，没有 Math.random 或依赖上一帧的状态。
- [ ] 用 `mv_pack_preview_frame` 至少看了：0 秒、每个段落的中间、每次段落切换前后 0.3 秒、最后 2 秒。
- [ ] 没有空白帧、没有报错；每帧耗时 < 10 ms（硬上限 40 ms）。

## 画面质量

- [ ] 每个段落一眼能区分；第二次副歌比第一次更强或有新元素。
- [ ] 当前歌词总是清楚可读（背景清空一条、样式 3 或 2），逐词高亮与唱的词一致。
- [ ] 画面在拍点 / 低频上有明显反应，但不会每帧乱闪（闪烁频率 ≤ 每拍一次）。
- [ ] 中文宽字符对齐正确，边框不被挤歪；长歌词被截断而不是换行错位。
- [ ] 小窗口（约 60×18）和大窗口（约 160×48）都能看：没有越界、主体仍然居中。
- [ ] 前奏、间奏、尾声有完整画面；结尾有收束（淡出、定格或谢幕字样）。
- [ ] credits / notice 写清楚：歌曲版权属于原作者，素材来源与许可。

## 发现问题时

把问题写进 `notes/qa.md`（时间点、现象、原因、修改），修改后重新预览同一时间点，再继续下一条。
