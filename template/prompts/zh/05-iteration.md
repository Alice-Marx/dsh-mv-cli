# 05 迭代提示词（用户想改的时候直接复制给 AI）

每次只改一件事，改完用 `mv_pack_preview_frame` 预览相关时间点并跑一遍 04 自检清单。

- **整体更炫**：“副歌加强：拍点（ctx.beat.pulse > 0.7）时全屏闪白一帧并整体放大 10%，加入 post-effects 的扫描线和暗角，其余段落保持不变。”
- **更贴歌词**：“主歌改为逐词打字：只显示 ctx.lyric.words 里已经唱到的词，当前词用样式 3，下一句用样式 0 预告在下方。”
- **节奏不准**：“把 canvas.bpm 改成 <BPM>，canvas.beatOffset 改成 <秒>，让第一拍落在 <时间> 秒；检查 <时间> 前后 2 秒的预览。”
- **段落不对**：“按这些时间重写 x-dsh-mv-ai.sections：<kind start–end 列表>，场景随之调整。”
- **太慢 / 卡顿**：“找出每帧最慢的段落，把粒子数改成与面积成比例（cols*rows/50），去掉每格内的嵌套循环，目标每帧 < 8 ms。”
- **换风格**：“保持结构和歌词同步不变，把整体风格换成 <风格>：调色只用样式 <列表>，字符集换成 <字符>。”
- **加一个场景**：“在桥段加入 examples/<示例名>.scene.js 的效果，改成适合本歌的文字和节奏，与前后段落用 0.8 秒淡入淡出衔接。”
- **小窗口难看**：“在 cols < 70 或 rows < 20 时使用简化布局：隐藏装饰边框，只保留主体和歌词。”
- **准备发布到工坊**：“检查 credits / notice / x-dsh-mv-workshop.license 是否完整；确认包里没有音频和歌词原文以外不该有的文件（发布时插件会自动剥离音频和歌词文本，只保留时间轴）。”
